# My_Agent

矿山数字孪生 AI Agent —— 面向 Unity 数字孪生项目的本地化 AI Agent 工程。

## 目标

在本地 AI 服务器上私有化部署一套专注 **数字孪生 - 矿山行业** 的 AI Agent，
支撑整个 Unity 数字孪生项目的开发与运行。

## 当前阶段

**初始选型阶段**。已完成开源生态调研与架构选型，结论见：

- 📄 [矿山数字孪生 AI Agent 选型与架构决策报告](docs/00-AI-Agent选型与架构决策报告.md)

### 核心结论

> **不复用是浪费，全自研是自杀。正确姿势：复用骨架 + 自研灵魂。**
>
> - **80% 复用**成熟开源：LangGraph（编排）、MCP（协议）、CoplayDev/unity-mcp（Unity 桥接）、RAGFlow（知识库）、vLLM（推理）
> - **20% 自研**领域层：矿山本体、工艺规则库、安全校验引擎、孪生 MCP 工具集、语料与蒸馏、评测集
>
> 那 20% 才是真正的护城河。
